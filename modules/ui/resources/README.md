# 界面素材

maps/battlefield.png 为 1662 × 946 的场地高清重建版，来自工作区已生成的 battlefield-top-view-restored-v1.png。原始参考为 2027 比赛规则 V1.0.0 印刷页 29 的图 4-1。

该图经过 AI 高清重建，局部纹理、标线可能与原图不同，仅作为当前桌面底图。不能用它测量精确场地尺寸或直接确定世界坐标映射。

图片通过 Qt 资源系统编入桌面程序。当前没有采用分割素材、设施图层或独立点击区域。

## RM26 参考素材

`images/` 中的顶部背景、基地血条、地图阵营圆环、朝向箭头、机器人编号及哨兵图标来自相邻项目 `RM26_Client/resources/models/images/`，保留对应相对目录；按用户要求暂时复用，用于当前信息展示。没有复制 RM26 的角色规则或 MQTT 处理逻辑。

`BaseHealthBar.qml` 与 `OutpostStatusBadge.qml` 移植自 RM26 的同名组件，资源路径改为本项目内部路径；保留基地双层血条及动画、前哨站原卡片布局。基地上限调整为当前 10000，深浅层按 60% / 40% 分配；未知值显示“—”，不沿用旧赛季默认血量与重建次数。

`BaseHealthWing.qml` 参考 RM26 的完整侧翼组合接入 R 队徽、基地状态行与 `buffs_new/defence_100.png` 防御图标。宽屏整条顶部栏统一缩放，避免队徽与计时面板相互脱节；窄屏调整为两行。基地状态仅采用 2027 `base_status`，不移植旧版根据前哨站存活推断基地无敌的逻辑。
