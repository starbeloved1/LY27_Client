# 2027 协议接入说明

## 依据和范围

依据工作区中的《RoboMaster 2027 机甲大师高校系列赛通信协议 V1.0.0（20261029）》第 2 章，独立整理 `modules/protocol/rm2027.proto` 和 `modules/protocol/messages.json`。协议清单记录源文件 SHA-256、章节、方向、最高 QoS 和频率说明，不从 RM26 的 schema 推导新赛季定义。

- 32 个 Topic 中，23 个入站、9 个出站。订阅列表只包含入站 Topic，不使用通配符，也不根据尚未核实的席位权限擅自过滤。实际服务器可能按身份或条件限制消息推送。
- 保留官方字段号、类型和 `optional` 语义。显式的零值与缺失字段分别表示，例如装配 `operation=0` 可以正常序列化。
- 使用 2027 的 R/B 前哨站、控制度字段和机器人字段定义，不订阅旧赛季部署模式、空中支援等旧 Topic。
- `MessageCodec` 返回类型化 Protobuf 消息及诊断 JSON。JSON 使用原字段名；Protobuf 的 `uint64` 按标准 JSON 规则输出字符串，`bytes` 输出 Base64。
- 空 Protobuf 消息可能合法，解析成功只表示线格式可读，不表示业务状态有效；业务有效性和过期处理在第三步实现。
- 未知字段按 Protobuf 的兼容规则保留；不能仅凭解析成功判断载荷一定来自正确的 Topic。

## 雷达汇总消息歧义

原文第 67–68 页中，外层定义为 `repeated uint32 RadarSingleRobotInfo;`：缺少字段编号，且类型与紧随其后的单机器人结构描述不一致。该定义无法直接生成有效 Protobuf，也不足以确定是整数列表还是嵌套消息列表。

当前处理：

1. 继续订阅 `RadarInfoToClient`。
2. 原始二进制完整保存在 MQTT JSONL 记录中。
3. 输出 `unresolved_schema`，不构造或展示推测的机器人位置。
4. `RadarSingleRobotInfo` 单体结构按原文保留，外层结构待官方勘误、官方有效 `.proto` 或真实样本确认后接入。

其余 22 个入站 Topic 可以正常按定义解析。出站 9 个消息已定义和支持通用编码，但没有装配、兑换等业务操作入口。

## 发送与接收边界

- `MqttTransport::publish` 是通用通信能力，不解释指令、不限制业务发送频率，也不提供角色授权。
- `MessageCodec::encode` 检查出站 Topic、类型匹配和自定义载荷长度；`CustomControl` 最大 60 字节，接收 `CustomByteBlock` 最大 300 字节。
- 通用传输只接受 QoS 0/1，发布不设置 retained，不在断线时缓存指令。
- `publishQueued` 表示 Paho 接受发送请求，`publishDelivered` 表示传输完成；两者均不表示赛事操作成功。
- 第四步再接入 `modules/commands/`，统一进行角色、参数、状态检查和限频。地图发送间隔需要按第 1.3.1 节区分身份和控制方式，清单中的 2 Hz 是最高值，不能直接用于所有角色。
- 地图消息的 `mode`、`type` 按原文 schema 保留字段号，业务含义与枚举映射在第四步单独核对。

## 连接、回调与退出

使用 Paho `MQTTAsync`，网络连接和收发由库的后台线程完成。所有状态更新回到 Qt 对象所属线程，回调内不创建或销毁客户端。

- 连接失败和断链以 1 秒起步、最多 30 秒退避重试；重连成功重新订阅。
- 协议、身份和认证被明确拒绝时停止自动重试并保留错误。订阅被拒绝不会标记为就绪。
- 每次停止递增会话代号，旧代回调不会更新新会话；先销毁客户端，再释放回调上下文。
- `ready` 表示全部入站订阅得到成功确认，不等同于所有赛事数据都已到达。

## 原始记录与诊断

启用 MQTT 后，每个运行会话创建独立 `mqtt_<session_id>.jsonl`。每行包含会话、Topic、QoS、retained、本地 UTC 接收时间、稳态时钟纳秒、解析状态、字段和原始载荷 Base64。

这些记录是协议排障材料，尚未实现第七步的同步回放。文件写入失败会输出错误；单条超过 1 MiB 的消息在回调处丢弃并报告，不复制进事件队列。原始消息记录采用同步写入，后续根据真实负载验证是否需要改为有界异步写入。

当前已使用本地 Mosquitto 进行订阅、传输发布、恢复连接及 CLI 联调；官方赛事引擎身份、权限、消息条件和真实吞吐仍需现场验证。
