# 地图阵地范围与流动光带

依据工作区《RoboMaster 2027 机甲大师超级对抗赛比赛规则手册 V1.0.0（20261015）》印刷页 96 的表 5-20 和印刷页 102 的图 5-23：前哨阵地包含前哨站增益点与中央高地增益点，基地阵地包含基地增益点与堡垒增益点。用户确认每侧前哨相邻范围合并，基地和堡垒分开，故全场绘制六个轮廓：红蓝前哨各一块，红蓝基地与堡垒各一块。

该层仅用于战术示意。轮廓参照规则增益点分布并沿现有 1662×946 高清底图校准；底图经过 AI 重建，局部不完全对称，红蓝前哨分别校准，不能把这些轮廓当作真实场地交互模块卡的精确检测边界。不会由机器人是否进入图形范围推导激活、占领或控制度，也不改变模拟服务器规则。

## 效果与定位

`TerritoryOverlayItem` 使用 C++ `QQuickPaintedItem` 绘制柔光轮廓，以及裁切在区域内的一排排斜向光带。轮廓按实际控制方显示红色／蓝色，完全控制为实线，临时控制为虚线；未知、缺失或过期为中性灰白。光带保留偏白的亮色，只轻微带入控制方色调，不整片铺红或铺蓝。光带加粗、提亮，缓慢平移并轻微波动，轮廓几何固定，不随时间摆动。

叠加层填满 `mapMarkerLayer`，与底图实际绘制区域对齐，不把窗口留白计入场地；随红蓝视角做同样的 180° 翻转，红蓝颜色始终指实际队伍，不随观看视角或通信身份变色。机器人、设施图标和血量条绘制在上层；车号有细白边与深色外描边，血条保留深色槽，避免和光带混在一起。叠加层不接收鼠标事件。

## 状态与激活提示

`TerminalViewModel::territories` 将四个逻辑阵地适配为绝对红蓝归属。前哨控制枚举 1/2 为己方完全／临时，3/4 为对方临时／完全；基地按原始拥有方解释：1 为原方完全控制，2 为对方临时控制。基地与堡垒两个轮廓共用同一个基地状态，不独立推断。数据来自 `GlobalUnitStatus` 的类型化状态，不从地图机器人位置计算。

已有新鲜的阵地激活提示（机制 3–6）额外产生推进方颜色的流动高光及秒数，但不会提前改变当前控制方。秒数直接采用上报值，不本地递减；暂停、过期、断线、重连未恢复、retained 或换局清除推进提示。机制 1/2 是堡垒特殊机制，不当作基地占领倒计时。相邻基地／堡垒同步高光，秒数仅在基地处显示一次；小地图空间不足时隐藏文字。占领状态本身独立检查新鲜度；有效的未知归属可同时出现另一路新鲜推进提示，不因此猜归属。

效果约 30 帧/秒，使用真实时间推进，同一轮廓不随通信消息销毁重建。窗口或该层隐藏后停止计时，恢复显示后继续。独立 `phase` 与 `animating` 属性便于确定性截图与检查，不参与比赛计时。

## 归属转换动效

新鲜、已知的归属或临时／完全状态发生改变时，使用 600 ms 的缓入缓出过渡：边框与内部光带的轻微色调连续插值，实线的间隙逐渐打开成为虚线，反向则逐渐闭合。不闪烁整块区域、不改变轮廓几何，也不推迟业务状态更新。倒计时期间的推进高光仍独立显示；只有占领状态上报改变才触发归属转换。

基地与堡垒共用一条动画，始终同步。重复报文、秒数刷新和视角翻转不重启动画；过渡中再次改变状态，从当前中间帧接续。首帧、未知恢复和重连快照直接显示当前状态，失效立即回到灰白，避免旧阵营颜色残留。隐藏窗口或关闭 `animating` 时直接完成过渡，重新显示不补播旧动画。

## 验证

`test_territories` 验证六个区域的关键点、基地与堡垒间道路不合并、红蓝翻转、发光不越出范围及柔光边沿、光带确实移动、周期相位、隐藏停止与恢复、不同分辨率和底图的对齐；另穷举红蓝通信身份下全部合法占领组合，检查临时／完全、基地与堡垒联动、正负激活计时、缺失、非法值、过期、retained、重连及换局。另验证转换首帧连续、中途反转、虚实线变化、倒计时不重播和失效清理，并保存转换的首帧／中间帧／完成帧。截图位于 `build/local-dev/tests/test-artifacts/territories-*.png` 和 `territory-control-*.png`。轮廓和视觉效果需结合实际场地与后续官方地图继续校准。
