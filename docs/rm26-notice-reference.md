| 新增一次小能量机关机会 | 0:00、1:30 | 7:00、5:30 |

节点前 5 秒预告，连续观测到发放节点后短暂提示新增机会。没有把“机会发放”写成“机关已激活”“闸门已开启”或“当前还剩几次”。开局提示使用真实开局 0 秒，去掉旧实现的 6:59 特例。

使用同局、同连接且有效的 `GameStatus` 已经过时间及剩余时间，合计必须为七分钟；时间跳变不会补播跨过的历史节点。中途启动、重连、过期后恢复不补播过去机会；暂停和非战斗阶段隐藏。已播节点同局去重，准备阶段及换局重置。未来五秒内的节点允许重新预告。只按服务器比赛时钟更新，不拿电脑实时时钟替代。

## 实现与验证

`MatchNotices` 读取类型化状态，负责时钟连续性、会话隔离和提示生命周期；`EventListModel::eventPresentation()` 共用事件文案；QML 只排版、淡入淡出。时间节点、实时事件及机制激活计时共用 `BattleNoticeCard.qml`，采用原阵地提示的 `HudPanel` 切角底框，同尺寸、同文字层级，在地图上方从左往右排列，空间不足时换行，超过可用高度可纵向滚动，静止时只展示完整行，并有细滚动指示。机制按 ID 固定六个槽位，时间节点也按稳定 ID 保持槽位，以保留 Canvas；本机 Buff 在小窗口单独留出位置。击杀与前哨摧毁图形播报固定在地图上方中央，层级高于这组通告，不随卡片数量向下避让。不改变消息筛选、最新事件替换或过期策略。

`AnimatedNotice.qml` 在展示层保留离场快照：入场从上方 20 px 模糊淡入，离场上移并模糊淡出，约 420 ms；旧框离场完成后，其余框以 380 ms 平滑补位。倒计时刷新只更新文字，不重置动画；离场中同一消息恢复时，从当前透明度和位移继续。新事件替换旧事件时先离场再入场。Qt Quick Effects 的模糊层仅在出入场期间启用，软件渲染自动保留位移和透明度动效。比赛暂停、比赛状态失效、断线和会话/局次变化立即清除快照，不把旧提示带到新比赛。

`match_notices` 测试覆盖全部 27 节点、两种模式及红蓝身份、空参数事件、无效参数、重复事件、旧编号语义、retained/断线/暂停/过期/换局、时钟快进回拨与小窗口截图。另验证两种角色下机制、预告、事件同框尺寸、横向换行、滚动后末行可见，以及击杀播报固定位置和上层覆盖。动效检查覆盖入场/离场中间帧、离场保留文案、右侧平移补位、倒计时不重播、过渡中恢复以及断线即时清理，并分别验证软件渲染和 OpenGL 模糊层。截图在 `build/local-dev/tests/test-artifacts/match-notices-*.png` 和 `unified-notices-*.png`。
