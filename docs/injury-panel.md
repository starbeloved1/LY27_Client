# 伤害面板

数据对应 2027 通信协议 §2.2.8 `RobotInjuryStat`，表示当前机器人本次存活期间的累计受伤，不是全队累计攻击伤害。复用 RM26 伤害面板的暗色浮层、金色标题、弹丸图标和数值／占比排列，独立接入现有类型化状态。

## 查看

平时隐藏；按住键盘左上角反引号／波浪号键显示，松开收起。兼容 Shift 波浪号、死重音键和 Windows OEM 键。系统自动重复的松键不收起面板；失焦、切换窗口、隐藏和关闭窗口都会收起，避免漏收松键后常驻。文本输入框编辑时以及 Ctrl/Alt/Meta 组合键不会打开。该快捷键仅控制本地界面，不发布 MQTT，也不启用 `KeyboardMouseControl` 上传。

面板是临时浮层，不改变地图和常驻面板布局，不抢占鼠标焦点；小窗口按比例缩放。面板常驻创建，显示时更新可见性。

## 数据

`TerminalViewModel::injury` 从 `StateStore::self()` 获取 `InjuryState`，由 C++ 整理展示字段并计算占比，QML 不解析协议。八个分类分别为 17mm、42mm、撞击、飞镖溅射、模块离线、异常离线、判罚、服务器强制战亡，不把飞镖或强制战亡合并为“警告”。占比以协议 `total_damage` 为分母，保留一位小数。

总量与分项均新鲜才显示占比；缺字段、retained、过期、断线和换局不会补零或保留过期值。总量和分项均为零时显示 0.0%；总量为零而分项大于零时占比显示“—”，不伪造百分比。总量缺失不妨碍显示仍有效的单项数值。数值保留完整 uint32 范围；视角翻转不切换数据所属机器人。

显示协议明确给出的击杀者；ID 0 标为“未知／环境伤害”，不猜测具体来源。未绑定机器人的指挥手身份显示未知，不将这个无 robot_id 的私有消息当作全场八车统计或自动套到哨兵身上。模块在线状态属于另一条协议，本次未增加其面板。
