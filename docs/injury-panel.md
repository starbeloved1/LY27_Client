# 伤害面板

数据对应 2027 通信协议 §2.2.8 `RobotInjuryStat`，表示当前机器人本次存活期间的累计受伤，不是全队累计攻击伤害。沿用 RM26 的伤害分类、弹丸图标和数值／占比排列，视觉统一为项目自身的切角面板、主题底色与边框；下方增加 §2.2.12 `RobotModuleStatus` 的模块状态。

## 查看

平时隐藏；按住键盘左上角反引号／波浪号键显示，松开收起。兼容 Shift 波浪号、死重音键和 Windows OEM 键。系统自动重复的松键不收起面板；失焦、切换窗口、隐藏和关闭窗口都会收起，避免漏收松键后常驻。文本输入框编辑时以及 Ctrl/Alt/Meta 组合键不会打开。该快捷键仅控制本地界面，不发布 MQTT，也不启用 `KeyboardMouseControl` 上传。

面板位于窗口右侧，距右边缘 12 px，垂直居中，是临时浮层，不改变地图和常驻面板布局，不抢占鼠标焦点；图传模式也可按住原快捷键临时查看。设计尺寸 360×704，窄小窗口按整体比例缩放，外框和全部模块卡片保持在窗口内。面板常驻创建，显示时更新可见性。

## 数据

`TerminalViewModel::injury` 从 `StateStore::self()` 获取 `InjuryState`，由 C++ 整理展示字段并计算占比，QML 不解析协议。八个分类分别为 17mm、42mm、撞击、飞镖溅射、模块离线、异常离线、判罚、服务器强制战亡，不把飞镖或强制战亡合并为“警告”。占比以协议 `total_damage` 为分母，保留一位小数。

总量与分项均新鲜才显示占比；缺字段、retained、过期、断线和换局不会补零或保留过期值。总量和分项均为零时显示 0.0%；总量为零而分项大于零时占比显示“—”，不伪造百分比。总量缺失不妨碍显示仍有效的单项数值。数值保留完整 uint32 范围；视角翻转不切换数据所属机器人。

显示协议明确给出的击杀者；ID 0 标为“未知／环境伤害”，不猜测具体来源。未绑定机器人的指挥手身份显示未知，不将这个无 robot_id 的私有消息当作全场八车统计或自动套到哨兵身上。模块在线状态独立来自 §2.2.12，不从伤害量或图传有无画面推断。

## 模块状态

从当前绑定机器人的 `RobotModules` 读取装甲、图传、17mm 测速、42mm 测速、RFID、UWB 定位、灯条、电源管理、电容和主控，按两列五行显示。在线（1）为绿色，离线（0）为红色，因安装不规范被视为离线（2）显示黄色“安装异常”；缺失、过期、retained、断线、换局和未识别值显示灰色“未知”。模块与伤害统计各自按原 Topic 有效期更新，互不刷新有效性。

27 协议只有装甲整体字段，不拆成装甲 0–3，也没有独立 Wi-Fi 状态；不添加假值占位。`modular_42mm` 是重装安装权限，不作为模块在线状态。无绑定机器人的指挥身份保持未知，视角翻转不改变所属机器人。

图传页左下本机血条下方也常驻展示同一组十类模块，布局直接复用 RM26 `LeftBottomPanel.qml`：位于 `statsArea.bottom`，左边距为面板宽度的 8%，五列两行，单格宽为 13%、高为面板高度的 10%，间距为宽度的 0.43%；使用原版普通白字和拉伸信号灯，不增加字重或均分铺满整块面板。图传、RFID、UWB、17mm、42mm 沿用旧位置，其余槽位分别放入主控、电源、电容、装甲和灯条，保留 27 的实际模块含义。面板整体沿用 26 的 1530×910 尺寸基准。采用 RM26 单个斜向信号灯素材，绿／红／黄／灰含义与本面板相同。其数据直接绑定同一 `injury.modules` 展示列表，不依赖伤害消息、视频帧或浮层是否打开。27 不提供 26 的独立遥控器／自定义控制器在线字段，不沿用旧标签或通过 MQTT、UDP 连接推断这些状态。指挥手未绑定机器人时，整块本机状态隐藏。

## 验证

`test_injury` 检查按住／松开、自动重复、失焦收起、文本编辑冲突、红蓝身份、八类字段及占比、零值、缺失、uint32 上界、过期、retained、重连、换局和无机器人绑定。新增检查十类模块的字段映射、三种状态与未知、两类数据独立过期、部分缺失及异常值、身份／断线／换局隔离；在 1280×800、1920×1080、640×480 和 640×900 下检查右对齐、缩放及完整网格不溢出。截图输出到 `build/local-dev/tests/test-artifacts/injury-*.png`。目前完成本地 Qt 离屏验证，尚未验证比赛现场键盘与输入法组合。

`test_player_ui` 另外检查图传页十类信号灯的映射、实际素材加载、红蓝本车、独立过期与非法／缺失字段、断线重连／换局和三种分辨率下的两行布局；截图为 `test-artifacts/player-modules-*.png`。
